Good analysis starts with boring work

  1. 01

    Start with the requirement call

    I'm the main client contact on several projects, so I hear first-hand which decision the dashboard has to support.

  2. 02

    Clean it once, in Power Query

    Mixed date formats, duplicate rows and three spellings of one customer get fixed in the ETL, not by hand every week.

  3. 03

    Model it with DAX

    A clean data model with the measures for year-over-year and customer comparisons built in.

  4. 04

    Deliver and keep people updated
